Shayan's Portfolio Website

About This Project

This is my personal portfolio website for my HTML and CSS assignment. I created it to introduce myself, share some of the projects I've worked on, and provide a way for people to contact me.

I wanted the website to have a modern look, so I used a dark background with blue, purple, and cyan accents. I also added gradients and hover effects to make the pages more interesting.

Pages

The website has four pages:

Home (index.html) – Introduces the website and provides links to the other pages.

About Me (about.html) – Includes information about me, a photo, and an introduction video.

Projects (projects.html) – Shows some of the projects I've worked on.

Contact (contact.html) – Includes a contact form and my contact information.

Files and Folders

index.html, about.html, projects.html, and contact.html contain the HTML for each page.

style.css contains the main styles used throughout the website.

phone.css adjusts the layout for phone screens.

tablet.css adjusts the layout for tablets.

laptop.css adjusts the layout for larger screens.

images/ contains the images and video used on the website.

Responsive Design

I used separate CSS files to make the website work on different screen sizes.

Phone: 480 pixels wide or less.

Tablet: 481 to 959 pixels wide.

Laptop: 960 pixels wide or more.

I checked the layout at different screen sizes to make sure the website stayed readable and the content fit properly. The CSS breakpoints are 480 pixels and below for phones, 481–959 pixels for tablets, and 960 pixels and above for laptops.

Colours and Gradients

I chose a dark navy background with blue, purple, and cyan accents. I used these colours to keep the design consistent across all four pages.
I chose these colours to give the website a consistent look across all four pages. The dark background makes the lighter text easier to distinguish, while the blue, purple, and cyan accents help headings and other important elements stand out. The gradients also add some variation without changing the overall colour scheme.

Some of the main colours are:

Dark navy: #0b1020

Blue: #123e62

Purple: #542b78

Cyan: #00e5ff

Light text: #e6edf7

I used two types of linear gradients in the CSS:

Angled gradient: The header uses linear-gradient(135deg, #111a35, #123e62, #542b78).

Regular gradient: The content sections use linear-gradient(to right, #1b2942, #202c49).

Testing/Troubleshooting

I checked my HTML using the W3C HTML Validator and my CSS using the W3C CSS Validator. I also checked the links and reviewed the website for spelling and accessibility issues.

I also had to troubleshoot issues with GitHub not updating my changes immediately, so I learned to commit and push my files and refresh the website to check for updates. Using the W3C validators also helped me find and fix coding errors, making sure my website worked properly across different pages and screen sizes. File paths were a problem, making sure everything is exactly the same path including capitilization helped me learn that github is heavily case sensitive.
